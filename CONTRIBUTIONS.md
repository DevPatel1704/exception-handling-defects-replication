## Note on tooling (LLM disclosure)

No LLM is used anywhere in the analysis pipeline (data collection, modelling, evaluation), so there are no model
identifiers, sampling settings or prompts that affect any result. Separately from the pipeline, an AI coding assistant
(Claude, Anthropic) was used to help draft scripts and documentation, as disclosed in the Milestone 2 report. The team
reviewed and owns all code; every reported number comes from executing the committed code.
